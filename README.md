# ai-learning-roadmap

* 主项目：共享单车需求预测（数据清洗 → 时间划分 → 基线 → 模型对比 → 误差分析 → demo）
* 目标：寒假实习前交付可投递作品集
* 周期：2026.10.26–2027.1.17，每周 AI 专项 9 小时
* 检查点：第4周投第一批，第7周收尾，第8–9周让路期末

* \## 数据探索初步发现 (EDA)
* 1\. 整体趋势：从 2011 到 2012 年，整体租车需求量呈明显上升趋势。
* 2\. 时间规律：一天中租车最高峰出现在早上 7-8 点，说明存在明显的通勤刚需。
* 3\. 工作日对比：工作日的平均租车量略高于非工作日，工作日通勤是核心场景。

* \## 基线模型结果
* \- 数据划分方式：按时间划分（前20个月训练，后4个月测试）
* \- 模型：线性回归
* \-MAE: 136.23
* \-RMSE: 181.38

* \## 模型对比结果
* \- 线性回归 MAE: 136.23, RMSE: 181.38
* \- 随机森林 MAE: 47.48, RMSE: 72.71
* \- \*\*结论\*\*：随机森林由于能捕捉复杂的非线性规律（如早晚高峰），效果远好于线性回归，误差降低了 65%。

* \## 模型可解释性与误差分析
* \- \*\*特征重要性\*\*：`hr`（小时）是预测租车量的绝对核心特征（重要性占比60%），其次是温度（13%），符合通勤刚需逻辑。
* \- \*\*误差分析\*\*：在天气类别3（小雨/雪）时，模型平均误差从45飙升至66，说明极端天气下预测难度显著增加，存在业务不确定性。
